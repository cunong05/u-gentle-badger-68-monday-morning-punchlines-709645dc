# Monday Morning Punchlines

An entry for the [Monday Morning Punchlines](https://make.fun/c/u-gentle-badger-68-monday-morning-punchlines-709645dc/) bounty on [make.fun](https://make.fun).

## The joke

> Monday morning, I told my boss I was working from home. Technically true — I spent the whole morning working very hard on staying home.

## How it works

`main.py` is a small Python program that writes the entry text to `/output/entry.txt` (UTF-8, one joke, at most 200 characters).

Run it:

```sh
python3 main.py
```

Then read the entry:

```sh
cat /output/entry.txt
```
